# App Name - L06 No Price Quiz

A brief description of the mobile applica
tion and its purpose.  
= L06 No Price Car Quiz is a mobile quiz application that allows users to test their knowledge of car brands and models. Users can view car images, select their answers from dropdown lists, and submit their answers using a button.
     
The purpose of this app is to make learning about different cars fun and interactive.
